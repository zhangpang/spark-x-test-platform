# ADR-0001：独立通用平台与系统适配器边界

- 状态：已接受
- 日期：2026-08-13

## 背景

最初需求来源于星火 Agent 的聊天、工具调用、知识库、Skill、MCP、自动任务和最近会话回归，但平台未来需要接入其他系统。把测试能力直接建设在星火 Agent 仓库中会导致用例、执行基础设施和被测系统发布生命周期耦合。

## 决策

建设独立仓库、独立部署和独立数据库的通用自动化测试平台：

- 平台核心只认识系统、环境、用例、套件、计划、运行、步骤、断言、Worker、适配器和附件等通用概念。
- 特定业务动作及断言通过版本化适配器提供。
- 自动化业务回归用例在平台数据库中维护；项目单元测试继续留在各项目仓库。
- 平台可通过 API/Webhook 与发布平台联动，但不共享核心数据库。

## 结果

- 星火 Agent 作为首个适配器接入，不决定平台核心模型。
- 平台必须同时支持无 SDK 的浏览器/HTTP 黑盒接入和可选的结构化遥测增强。
- 需要额外建设适配器 SDK、兼容性校验和分布式 Worker 协议。
- 第一版会牺牲部分通用高级功能，优先用星火 Agent 的 32 个案例证明架构闭环。
