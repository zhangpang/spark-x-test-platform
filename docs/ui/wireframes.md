# MVP 页面信息架构与线框

## 1. 全局结构

第一版内部匿名使用，不显示登录入口和权限管理。所有页面保留统一的系统、环境上下文以及平台运行状态。

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 星火自动化测试平台       [系统: 星火Agent ▾] [环境: 测试环境 ▾] ●正常 │
├───────────────┬─────────────────────────────────────────────────────┤
│ 系统与环境     │                                                     │
│ 用例库         │                  当前页面内容                       │
│ 公共步骤       │                                                     │
│ 测试套件       │                                                     │
│ 运行中心       │                                                     │
│ 定时计划       │                                                     │
│ 平台配置       │                                                     │
└───────────────┴─────────────────────────────────────────────────────┘
```

## 2. 系统与环境

目标：登记被测系统、模块、环境、白名单、动作等级、并发和适配器配置。

```text
┌ 系统与环境 ─────────────────────────────────────────── [新建系统] ┐
│ 星火 Agent  active   7个模块   1个环境   并发上限 5                │
├───────────────────────────────────────────────────────────────────┤
│ 环境          类型   地址                 权限   健康     操作      │
│ 测试环境      test   192.168.110.136      写入   ●正常    [检查]    │
├───────────────────────────────────────────────────────────────────┤
│ 环境编辑：基本地址 / 主机端口白名单 / 动作等级 / 时区 / 并发       │
│           适配器及版本 / 非敏感配置 / 密钥引用                     │
└───────────────────────────────────────────────────────────────────┘
```

保存环境时必须先展示实际允许的目标范围；危险等级使用明确警示，不能用普通勾选框误开。

## 3. 用例库与用例编辑器

```text
┌ 用例库 ─────────────────────────────────────────────── [新建用例] ┐
│ 搜索...  [模块 ▾] [P0-P3 ▾] [状态 ▾] [标签 ▾] [导入] [导出]       │
├───────────────────────────────────────────────────────────────────┤
│ P0  B2C订单文件准确检索  知识库  已发布 v3  graybox   2小时前      │
│ P0  工具参数绑定           工具    草稿 v2    graybox   1天前       │
└───────────────────────────────────────────────────────────────────┘

┌ 编辑用例：B2C订单文件准确检索 ───────── [保存草稿] [校验] [发布] ┐
│ 基本信息 | 输入与数据集 | 执行步骤 | 清理 | 版本                    │
├───────────────────────────────────────────────────────────────────┤
│ ① 准备知识库和文件          adapter:.../prepare       [复制][删除] │
│ ② 发送订单问题              adapter:.../chat.ask      [复制][删除] │
│    ├─ 必须使用 B2C订单文件                                   hard │
│    ├─ 禁止使用 科目表                                        hard │
│    └─ 回答包含订单事实                                       soft │
│ ③ if / foreach / 公共步骤                                    [+]  │
├───────────────────────────────────────────────────────────────────┤
│ finally: 清理本次运行创建的知识库                               [+] │
└───────────────────────────────────────────────────────────────────┘
```

编辑器采用表单式步骤列表，支持折叠、拖动排序、复制、条件和受限循环。右侧属性面板由动作/断言 Schema 自动生成。发布失败时错误必须定位到具体字段和步骤。

版本页展示结构化差异和变更说明。回滚操作复制历史内容生成新草稿，不改变历史版本。

## 4. 公共步骤

```text
┌ 公共步骤 ─────────────────────────────────────────── [新建公共步骤] ┐
│ 名称              系统       当前发布版   被引用次数   状态           │
│ 登录星火Agent      星火Agent  v2           18           已发布         │
│ 创建隔离知识库     星火Agent  v4           6            已发布         │
└────────────────────────────────────────────────────────────────────┘
```

公共步骤编辑体验复用用例步骤编辑器。引用关系可查看；发布新版本不自动修改既有已发布用例。

## 5. 测试套件

```text
┌ 测试套件 ─────────────────────────────────────────── [新建套件] ┐
│ 核心冒烟        12例  P0   最近通过 100%             [运行]     │
│ 星火全量回归    32例  P0/P1 最近通过 93.8%            [运行]     │
├──────────────────────────────────────────────────────────────────┤
│ 套件编辑：用例搜索与勾选 / 标签规则 / 并发 / 诊断重试 / 门禁策略 │
└──────────────────────────────────────────────────────────────────┘
```

运行前确认框展示环境、被测版本、实际用例版本数、动作最高等级、预计并发和变量覆盖。

## 6. 运行中心

```text
┌ 运行中心 ───────────────────────────────────────── [一键回归] ┐
│ [运行中] [已完成] [门禁] [失败分类 ▾] [时间 ▾]                 │
├───────────────────────────────────────────────────────────────┤
│ #R1024 星火全量回归  running  18/32  56%  8m12s    [查看]       │
│ #R1023 核心冒烟      blocked  11/12  产品失败 1     [查看]       │
│ #R1022 核心冒烟      passed   12/12  3m40s          [查看]       │
└───────────────────────────────────────────────────────────────┘
```

列表明确区分产品、脚本、环境、基础设施和不稳定失败，不能只显示红/绿。

## 7. 运行详情

```text
┌ #R1024 星火全量回归 ───────── running ───────────── [取消运行] ┐
│ 环境: 测试环境  Commit: abc123  Worker: sha256:...  适配器: 0.1 │
│ 通过 20 | 产品失败 1 | 脚本失败 0 | 环境失败 0 | 运行中 11      │
├──────────────────┬─────────────────────────────────────────────┤
│ 用例/迭代         │ 当前选中用例                                │
│ ✓ 聊天基础流式    │ 时间线：准备 → 步骤1 → 步骤2失败 → 清理成功 │
│ ✕ B2C订单检索     │ 首次失败：错误使用“科目表.xlsx”              │
│ … MCP工具调用     │ [截图] [Trace] [工具调用] [命中文档] [日志] │
│                   │ 诊断重试：通过 → 最终分类 flaky             │
└──────────────────┴─────────────────────────────────────────────┘
```

页面通过 SSE 增量更新。断线重连使用 `Last-Event-ID`，不能要求刷新整页才能看到最终状态。

## 8. 定时计划

```text
┌ 定时计划 ─────────────────────────────────────────── [新建计划] ┐
│ 每日全量回归  0 2 * * *  Asia/Shanghai  下次 02:00   已启用      │
│ 每小时冒烟    0 * * * *  Asia/Shanghai  下次 17:00   已停用      │
└─────────────────────────────────────────────────────────────────┘
```

编辑页展示 Cron 的自然语言解释、下一次触发时间、套件、环境和运行变量。停用不删除历史运行。

## 9. 平台配置

包含：

- Worker 状态、镜像版本、能力和槽位；
- 已安装适配器及兼容状态；
- 密钥元数据与轮换，不显示原值；
- 默认附件保留策略；
- 回调目标；
- 操作审计；
- 备份和恢复演练状态。

第一版不包含用户、角色和权限页面。

## 10. 关键体验规则

1. 任何失败都能从运行详情下钻到具体迭代和步骤。
2. 任何危险操作都在用例和运行确认页明确展示。
3. 运行结果不会用重试成功覆盖首次失败。
4. 环境故障不会显示为产品失败。
5. 所有长操作返回任务 ID，并显示进度，不让页面请求长时间阻塞。
6. 空状态必须引导创建系统、环境、用例和套件的正确顺序。
